# API Reference

> **Empty by design.** This section will contain a page per implemented class, method, event, and type.

## Why it is empty

There is no implemented code to document. Writing reference pages for functions that do not exist would mislead developers.

## When pages will appear

A page will be added for a symbol only after:

1. The symbol is implemented in `packages/`.
2. It has tests.
3. Its behavior is stable enough to document.

## Template for future pages

Each reference page must include:

- Description
- Parameters and types
- Return value
- Errors thrown
- Example
- Minimum library version

## Current status

No symbols are documented yet.
