# Examples

> **Scaffolding only.** Most examples here are **non-runnable** because `@vexojs/sdk` is not implemented or published.

## Examples

| Folder | Purpose | Runnable |
|---|---|---|
| `hello-bot/` | Minimal bot skeleton | No |
| `ping-bot/` | Reply to `!ping` | No |
| `welcome-bot/` | Send a welcome message on join | No |
| `moderation-bot/` | Basic moderation commands | No |
| `slash-commands-bot/` | Register and handle slash commands | No |
| `typescript-bot/` | TypeScript setup example | No |

## Rules followed in this folder

- No example imports a package that does not exist and pretends it works.
- Every example README states clearly whether it is runnable.
- `.env.example` files contain placeholders only.
