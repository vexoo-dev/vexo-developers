# hello-bot

> **Non-runnable.** `@vexojs/sdk` is not published. This is a design example.

## Purpose

Show the smallest possible Vexo bot.

## Intended files

- `src/index.js` (illustrative)
- `.env.example`
- `package.json` (with `@vexojs/sdk` listed but not installable yet)

## Expected result

When the SDK is available, running this bot should log `Logged in as <bot>`, then do nothing until it receives a message.

## Status

Not runnable. Do not `npm install` in this folder.
